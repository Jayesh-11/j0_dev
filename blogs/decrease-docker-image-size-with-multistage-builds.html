Decreasing docket image size with multistage builds

Published: Jan 16 2026

In short: Multi-stage build.

I was building a Rust server to be deployed as a Docker image on a VM. Once I built it, the size of the image was 2.4GB!!!.

Where did this size come from? Mostly two places:

  1. the rust:trixie image was already big enough (~500MB)
  2. the installed Cargo dependencies, i.e the build artifacts (the rest) 
ARG RUST_VERSION=1.92.0
ARG APP_NAME=form_v2
FROM rust:${RUST_VERSION}-trixie AS build

ARG APP_NAME
WORKDIR /app

COPY . .

RUN cargo build --locked -r

CMD [".target/release/form_v2"]

BOOM!! 112MB

Just copying the built binary in a smaller base image i.e the new image does not have extra artifacts : 

ARG RUST_VERSION=1.92.0
ARG APP_NAME=form_v2
FROM rust:${RUST_VERSION}-trixie AS build

ARG APP_NAME
WORKDIR /app

COPY . .

RUN cargo build --locked -r

FROM debian:trixie-slim
COPY --from=build /app/target/release/form_v2 /

EXPOSE 8000

CMD ["./form_v2"]
